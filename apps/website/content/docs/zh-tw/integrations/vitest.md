# Vitest 外掛

Vitest 外掛還沒推出。它以 Vitest browser mode 為目標，沿用 [Cypress 外掛](/docs/integrations/cypress-plugin)的比對引擎與 [manifest](/docs/reference/manifest)，並把基準影像放在你的儲存庫裡，和測試擺在一起。

想在它推出時收到一封信？到 [Vitest 頁面](/vitest)留下你的電子郵件。
