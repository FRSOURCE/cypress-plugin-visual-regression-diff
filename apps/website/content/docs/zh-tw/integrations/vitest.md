# Vitest 外掛

Vitest 外掛即將推出。它以 Vitest browser mode 為目標，使用與 [Cypress 外掛](/docs/integrations/cypress-plugin)相同的比對引擎，寫出相同的 [manifest](/docs/reference/manifest)，並將基準影像存放在您的儲存庫中。

請到 [Vitest 頁面](/vitest)追蹤進度，上線時第一時間收到通知。
